# MEGAMAN — نسخة قابلة للتعديل في VS Code

النسخة دي فيها آخر ملفات الواجهة والـ API، ومجهزة للتشغيل محلياً بدون Replit أو Vite. بيانات العملاء والطلبات القديمة غير موجودة في الملف.

## التشغيل

المتطلبات: Node.js 20.6 أو أحدث، وVS Code.

1. فك ضغط الملف وافتح مجلد `MEGAMAN-VSCode` في VS Code.
2. افتح Terminal داخل المجلد وشغّل:

   ```sh
   npm install
   ```

3. انسخ `.env.example` إلى `.env`، ثم ضع كلمة مرور قوية عند `ADMIN_PASSWORD`.
   - Windows PowerShell: `Copy-Item .env.example .env`
   - macOS / Linux: `cp .env.example .env`
4. شغّل التطبيق:

   ```sh
   npm start
   ```

5. افتح `http://localhost:5000`.

## الصفحات

- المتجر: `/`
- دخول الإدارة: `/admin-login.html`
- لوحة الإدارة: `/admin.html`
- الموردين: `/supplier.html`

تقدر تعدل صفحات الموقع في `public/`، وطلبات الـ API في `server/megaman.cjs`.

## البيانات والإعدادات

- أول تشغيل ينشئ قاعدة JSON فارغة في `data/megaman/`؛ لا توجد سجلات العملاء أو الطلبات السابقة في هذا التصدير.
- ملفات إثبات الدفع تُحفظ محلياً في نفس مجلد البيانات.
- `ADMIN_PASSWORD` مطلوب لتفعيل دخول الإدارة؛ لا توجد كلمة مرور افتراضية.
- إعدادات WhatsApp اختيارية، ولن يعمل إرسال OTP بدون بيانات WhatsApp المعتمدة.
- ملف `.env` وبيانات التشغيل مستثناة من Git. لا تشاركها ولا تضع كلمات المرور في الكود.

## تنبيه قبل الاستخدام الحقيقي

التصدير مناسب للتعديل والاختبار المحلي، لكنه غير جاهز للنشر ببيانات عملاء حقيقية: بعض واجهات الموردين غير محمية بتسجيل دخول، واستعلامات العملاء والطلبات تحتاج حماية إضافية، كما أن حفظ JSON والملفات محلي وليس تخزيناً دائماً للإنتاج.
